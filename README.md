# Serverless Threshold Alert System

Цей проєкт реалізує безсерверну систему моніторингу з використанням AWS:

- **Lambda** – обробка вхідних метрик
- **API Gateway** – прийом HTTP-запитів
- **DynamoDB** – збереження порогового значення
- **SNS** – надсилання email-попереджень
- **CloudWatch** – логування подій
- **Terraform** – автоматичне розгортання інфраструктури

## Функціональність

- Приймає метрики через HTTP POST
- Перевіряє значення на поріг
- Надсилає email, якщо поріг перевищено
- Логи зберігаються у CloudWatch
